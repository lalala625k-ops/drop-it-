📲 怎么在手机系统分享里直接调用？

🤖 安卓 (Android) 用户：

1. 用手机 Chrome 或系统浏览器打开此页面。

2. 点击浏览器右上角菜单 “⋮” -> 选择 “添加到主屏幕” 或 “安装应用”。

3. 安装后，在手机相册、微信或浏览器中点击任何“系统分享”，在列表中就能直接看到 “便签同步” 图标，一键秒传！

🍎 苹果 (iPhone) 用户：

1. 打开 iPhone 自带的 “快捷指令 (Shortcuts)”。

2. 新建一个指令：接收“图像、文本、链接”，并在“共享表单中显示”。

3. 添加动作：“获取 URL 内容”，方法选 POST，地址填：http://电脑IP:8088/api/share。

4. 以后截图后直接点分享 -> 快捷指令，自动发送到电脑！
