# 图片带出处 · Edge 扩展

独立的 Manifest V3 扩展。直接在 Microsoft Edge 使用，不需要启动 Drop it，也不调用后端或图片溯源服务。

## 安装（Windows / macOS）

1. 解压扩展包，找到包含 `manifest.json` 的 `edge-image-source` 文件夹。已有源码时直接使用此目录。
2. 在 Edge 地址栏打开 `edge://extensions`，开启“开发人员模式”。
3. 点击“加载解压缩的扩展”，选择上述文件夹。
4. 在 Edge 工具栏的“扩展”菜单中，将“图片带出处 · Edge”固定到工具栏。

不需要 `npm install` 或构建。更新源码后，在扩展管理页点击“重新加载”。这是本地开发版，没有发布到 Edge 商店；Edge 可能提示正在运行开发人员扩展。

## 使用

在网页的**图片上右键 → 复制图片和原链接**。扩展图标显示 `✓` 后，切换到目标应用粘贴：Windows 用 `Ctrl+V`，macOS 用 `⌘V`。

一次写入一个 `ClipboardItem`，同时包含：

| 格式 | 内容 |
| --- | --- |
| `image/png` | 一张图片的完整像素，保留原始尺寸与透明度，不带文字或水印 |
| `text/html` | 内嵌 PNG 图片，下方是可点击的出处链接 |
| `text/plain` | 仅原网页 URL，适合地址栏或纯文本输入框 |

点击工具栏扩展图标可查看最近图片、尺寸与出处。出处可以手动修改，再点“复制图片和原链接”使修改进入剪贴板。若浏览器要求前台窗口才能写入，扩展会提示在此面板再次复制。

**粘贴的格式由目标应用决定。** 支持 HTML 的编辑器可以保留图片与链接；只接收图片的应用可以读 PNG；纯文本应用可以读 URL。有些应用会只选 PNG，或过滤内嵌图片、链接。Notion、微信、Photoshop、CAD 等具体版本的行为需要各自验证，扩展不能控制它们的选择。当前 Drop it 的粘贴接入未改动，因此此版本不承诺在画布上同时出现图片和链接。

## 保存到磁盘

- **保存图片与出处 · HTML**：保存一个 `.html` 文件，图片已经内嵌，断网也可查看；图片下方有可点击出处。用 Edge 双击打开即可。
- **仅保存 PNG**：保存纯像素图片，不附带出处文字。普通 PNG 文件不能直接在图片下方显示可点击链接。
- 原生右键“将图像另存为”保持浏览器行为。带出处功能通过扩展右键命令及面板使用，不拦截浏览器原有下载。

## 如何确定出处与图片

1. 如果图片本身包在指向内容页的超链接中，优先记录这个目标页面（例如列表里的文章封面或 Pinterest Pin）。指向图片文件或当前页锚点的链接不作为内容页。
2. 否则，采用图片所在网页的同域 `canonical` 正式地址；没有可靠地址时记录当前网页 URL。iframe 中的图片优先使用所在 frame 的网页地址。
3. 这是**记录采集时能取得的网页出处**，不是全网反向搜索，不能证明图片最早由谁发布。直接打开 CDN 图片后复制时，通常只能记录图片所在的地址。可在面板中纠正链接。
4. 优先读取网页实际声明的最大 `srcset` 版本，失败时回退到当前显示的图片。不猜测或改写各站 CDN 地址。正常远程图片会重新读取原图；Blob 图片或访问受限图片会尝试读取网页已加载的完整像素。
5. JPEG、WebP、AVIF 等浏览器可解码格式转为 PNG；GIF/动画图片取一帧。不是网页截图，不主动缩小图片。不支持 CSS 背景图、视频帧、canvas 或无法访问的浏览器内置页面。

单张输入图片与输出 PNG 各限制 24 MB，图片上限 4000 万像素。超过限制、登录失效、防盗链或跨域画布不可读时会明确报错；读取失败不会把原有剪贴板替换成只有链接的内容。

## 权限与隐私

- `contextMenus`：图片右键命令；`scripting`：只在执行命令时读取选中图片的网页信息。
- `offscreen` / `clipboardWrite`：解码图片并写入多格式剪贴板。
- `downloads`：用户点击保存时下载 HTML 或 PNG。
- `storage`：保存当前浏览器会话的操作状态，不永久收集图片历史。
- HTTP / HTTPS 网站权限：读取不同网站与 CDN 的图片。网络请求可能携带对应网站已有登录状态，以读取用户选中的图片；只请求图片地址，不向第三方服务器上传图片或链接。

没有常驻网页内容脚本，不扫描浏览历史，不读取 `.local.json` / `.local.csv` 或 API Key。最近图片仅暂存于扩展内存；关闭浏览器或重新加载扩展后消失。“清除预览”清除暂存图片，不改写系统剪贴板。

## 验证

纯逻辑测试：在此目录运行 `npm test`。

Edge 集成测试：使用 Playwright（可通过 `PLAYWRIGHT_MODULE_PATH` 指定模块路径），运行 `npm run test:edge`。通过 `EDGE_EXECUTABLE` 指定 Edge 路径；测试使用临时的独立浏览器资料，不加载个人资料。测试包含多格式写入、HTML 粘贴、纯文本粘贴、高清与跨域图片、Blob 图片、透明像素、保存页面、链接修改与失败保留剪贴板。

文件职责：`background.js` 负责右键及调度，`source-reader.js` 只在请求时读取页面，`offscreen.js` / `image-data.js` 负责图片处理，`clipboard.js` 负责三种格式的原子写入，`popup.*` 是操作面板，`core.js` 是出处与 HTML 规则。所有文件独立于现有画布。
